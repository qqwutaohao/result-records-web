# 结果记录台

一个无需安装依赖的响应式网页，用来快速记录三个骰子结果，并更新大小、单双两组历史模型参考值。

线上地址：<https://qqwutaohao.github.io/result-records-web/>

## 当前功能

- 首页只需输入三个 `1–6` 的数字，例如 `425`、`4 2 5` 或 `4,2,5`；
- 自动计算和值、大小和单双；三同号不计大小，但仍按和值计入单双；
- 大与小合计 100%，单与双合计 100%；
- 固定 `50% / 50%`、静态 `Beta(10,10)` 贝叶斯、带 20 轮半衰期的动态贝叶斯、分位置骰子偏差、忽略录入顺序的总体骰子偏差和按历史损失加权的组合模型同时在后台预测；
- 每条新记录都会冻结六套模型在开奖前给出的概率，并用同一批后续结果公平比较；
- 每 10 轮组成一个验证段：段开始时，大小和单双分别锁定一套冠军或挑战模型，段内不再切换；
- 第一段固定使用 50% 基准；之后没有模型胜出的一组自动保持 50%；
- 20–99 条标记为“实验领先”，100 条以上才标记为“当前最优”；
- 模型排行榜分别显示大小、单双与综合 Brier Score，并展示非 50% 方向的历史命中率；大小在后台按“大赢、小赢、三同号”三分类评分，不再跳过三同号；
- 大小的页面概率继续归一化为 100%，但信号使用扣除三同号后的实际胜率；单双直接使用实际胜率；
- 固定赔率 1.96 的盈亏平衡胜率为约 51.02%，只有点估计跨线且盈亏线序贯证据达标时才可能显示信号；
- 首段 10 轮只用于比较影子模型，不进入信号证据；之后只有开奖前已经锁定且完整结束的 10 轮验证段才累计证据；
- 每条新记录冻结协议轮号、段号、段内位置和锁定模型；删除单条记录不会把后续记录重新排段，缺失段自动退出验证；
- 删除 v4 验证记录会将所属场次证据整体作废，防止开奖后通过删掉不利结果制造假优势；
- 支持 Web Locks 的浏览器会串行处理多个标签页写入并同步最新记录；不支持安全多标签写入时会拒绝保存并提示关闭其他页面；
- 使用可反复查看的混合 e-process 代替普通固定时点区间和 400 次随机模拟；大小、单双两条主证据流分别检验；
- 盈亏线序贯证据达到 `×40`、当前完整验证段胜出且实际预测概率跨过盈亏线时，才可能显示试验信号；稳定信号还要求连续两段胜出、盈亏线证据达到 `×200` 且 Brier 优势证据达到 `×40`；
- 在每期开奖连续、完整、无选择且无重复录入的前提下，`×40 / ×200` 将单场内大小、单双任一误报的理论上界分别控制在 5% / 1%；漏记、挑选结果或反复新建场次都会使误报累积，不能把这些上界解释为跨场终身保证；
- 合格旧场次仅折算为 5 轮先验；当场最近 10 轮若与历史大小或单双频率相差超过 25 个百分点，立即停用历史预热；
- 使用双向 CUSUM 监测近期分布变化，触发后暂停信号并等待动态模型适应；
- 分别统计大小、单双的信号覆盖率与信号命中率，避免只看命中率而忽略系统实际输出了多少次；
- 对完整锁定策略计算相对理论基准的 Brier 平均优势与序贯 e-value，显示“收集中、优势未确认、序贯优势、未优于基准”；
- 旧场次不改变当前场次概率，只统计模型能否跨场重复胜出；至少 3 个满 40 轮的场次、同一模型胜出不少于 3 场且胜率达到 60%，才显示“多场稳定”；
- 跨自然日、间隔超过 30 分钟或点击“新场次”后重新累计，旧记录继续保留；
- 支持自定义标题、截图 OCR 补录、CSV 导出和本地历史长轴；
- 支持设置模拟本金，并手动记录大、小、单、双方向的金额测试；最低投入 2 元，固定十进制赔率 1.96；
- 旧版主播记录继续保留和展示为历史结果，但不再参与主播预判或主播命中统计。

## 验证

```powershell
node --test tests/model-core.test.cjs
node tests/fair-null-stress.cjs
```

压力测试默认生成 20,000 个、每场 120 轮的公平骰子场次，并在每个完整 10 轮段结束时检查大小与单双。验收上限为：整场出现任一试验信号的 95% Wilson 上界不超过 5%，任一稳定信号不超过 1%。该测试故意忽略部分生产门槛，因此是偏保守的误报上界检查。

## 打开方式

电脑直接双击 `index.html` 即可使用。

如需让同一 Wi-Fi 下的手机访问：

1. 双击 `start.bat`；
2. 电脑打开 `http://localhost:8080`；
3. 在 PowerShell 运行 `ipconfig`，找到电脑的 IPv4 地址；
4. 手机打开 `http://电脑IPv4地址:8080`。

截图识别第一次使用时需要联网加载 Tesseract.js OCR 组件和英文数字识别数据。图片在浏览器本地处理，识别候选必须人工核对后才会写入记录。

## 模型边界

模型输出是历史模型之间的样本外比较结果，不是开奖机制的真实预测概率。升级前记录和截图记录可以帮助计算当前概率，但不会进入 v4 的锁定验证证据。旧场次只以最多 5 轮的强度参与预热，不参与当前场次的序贯证据。若每期开奖结果相互独立且骰子公平，历史结果不会提高下一期长期命中率。金额功能只记录用户手动输入的测试，不推荐方向或投入额。
