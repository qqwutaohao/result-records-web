# 结果记录台

一个无需安装依赖的本地响应式网页，用于：

线上地址：<https://qqwutaohao.github.io/result-records-web/>

- 自定义页面大标题和浏览器标签名称，默认使用中性的“结果记录台”；
- 首页提供一分钟流程：先锁定主播的大小单双预判或选择“主播观望”，再录入开奖结果完成核对；
- 待验证预判会保存在当前浏览器中，刷新页面后仍可继续；
- 系统反馈同时展示理论概率、主播同方向历史命中和最近官方结果频率；
- 桌面首页右侧用无内层滚动的竖向长轴展示最近 10 条记录，手机端自动排到操作台下方；
- 录入官方三枚骰子；
- 在一个输入框内输入 `425`、`4 2 5` 或 `4,2,5`，自动拆分三枚骰子；
- 录入主播口播分类或三枚骰子；
- 将历史数字截图拖入页面，用浏览器本地 OCR 提取候选记录，确认后批量导入；
- 自动核对骰子、和值与大小单双方向；
- 设置模拟本金并按每轮投入记录资金变化；
- 按固定十进制赔率 1.96 记录返还、净盈亏和轮后余额；
- 展示 216 种组合枚举出的理论概率；
- 用浏览器本地存储保存记录，并导出 CSV。

本金、完整补录、截图识别、概率和历史记录默认收纳在“更多工具”中，避免影响一分钟内的主要操作。

## 打开方式

电脑直接双击 `index.html` 即可使用。

如需让同一 Wi-Fi 下的手机访问：

1. 双击 `start.bat`；
2. 电脑打开 `http://localhost:8080`；
3. 在 PowerShell 运行 `ipconfig`，找到电脑的 IPv4 地址；
4. 手机打开 `http://电脑IPv4地址:8080`。

Windows 首次运行可能弹出防火墙提示，只允许“专用网络”即可。关闭命令窗口会停止服务。

截图识别第一次使用时需要联网加载 Tesseract.js OCR 组件和英文数字识别数据。图片在浏览器本地处理，不会上传；识别候选必须人工核对后才会写入记录。通用识别优先适配截图中的数字结果，如果截图只有骰子点阵图，可能需要针对具体截图版式继续适配。

## 规则说明

默认采用常见快三规则：和值 4–10 为小，11–17 为大，三同号不计大小单双。页面可切换为把三同号并入对应分类。

金额测试每轮只选择一个项目（跟随主播大小或跟随主播单双），最低投入 2 元，不设固定金额上限，但不能超过当前模拟余额。赔率 1.96 含本金返还：赢时返还投入的 1.96 倍，净盈利为投入的 0.96 倍；输时返还为 0，净亏损为全部投入。

若每期开奖结果相互独立且骰子公平，历史频率不会改变下一期理论概率。本工具只记录用户自行输入的模拟金额，不提供逐轮下注金额或追损建议，不构成投注建议。
