# 结果记录台 · V5

无需安装依赖的响应式记录网页。线上地址：[打开记录台](https://qqwutaohao.github.io/result-records-web/)。

## 使用方式

1. 先录入本场历史：输入三个 `1–6` 的数字，如 `425`、`4 2 5`。每次记录后更新大小、单双估计，记满 10 轮后开始方向参考；没有明显倾向时仍会显示观望。
2. 开奖前填写完整期号，点击“锁定本期预判”。主播判断和本轮选择均为选填，需在锁定前填写。
3. 开奖后输入三个数字，自动核对当时锁定的预判，展示上一期反馈，再估计下一期。
4. 未锁定而直接录入的结果是“补录”，只帮助学习，不计入提前验证。没录到的期次使用“跳过并留痕”，不会补造命中。

时间由本机记录，无法核实官方开奖时间。请如实在开奖前锁定，并连续记录结果；本工具不是防篡改审计系统。

## 本版变化

- 首页优先显示大小、单双两张概率卡片，方向、简短原因、上一期反馈和输入框集中展示。详细验证、截图识别和模拟本金默认折叠。
- 大与小合计 100%，单与双合计 100%。大小是**排除三同号后的相对比例**；展开说明可看含三同号的三分类估计。三同号时大小均不命中，单双仍按和值。
- V5 主参考逐轮更新，不再等待完整 10 轮验证段换方向。10 轮只是开始显示参考的产品门槛，20、60 轮均不是准确或稳定保证。
- 可选填写最多两名主播的当期大小、单双判断。名称可增删改；未填写或观望不影响纯历史参考。姓名默认保留，判断每期重填。
- 先锁定，再验证。冻结当时的全部候选概率、理由、主播判断、个人选择和金额；锁定后不可修改，刷新或其他标签页也不能用新模型替换旧预判。
- 历史长轴优先显示大小、单双和预判反馈，最多直接展开最近 30 条，不设置独立内滚动条；更多记录在全部数据表中。
- 旧记录保留。V5 采用独立存储键，首次写入时从 v4/v1 迁移快照，不修改旧版存储；之后旧标签页新增的旧版数据不会自动合并进 V5。更新后请关闭旧页面并刷新。

## 模型与边界

V5 使用少量可解释模型，规则预先固定：

- 理论基准：大小条件比例及单双各 50%；公平三骰三同号率为 `1/36`。
- 近期偏向：Beta 收缩，大小/单双各侧 4 轮先验，近期半衰期 6 轮，最多参考 80 条。
- 前后顺序：一阶转移关系，半衰期 12 轮，以近期模型收缩 4 轮。截图不提供可靠邻接关系，明确跳过的期次会断开顺序关系。
- 历史组合：基准、近期和顺序三套模型按此前 Brier 损失加权，损失半衰期 20 轮、学习系数 4。手工补录时保存仅由更早历史算出的候选值，用于后续学习，但不当作开奖前验证。
- 主播关联：只参考本场中该主播、相同判断的已锁定结果，使用 12 轮收缩，影响权重不超过 35%。多人取平均，不把同向意见乘成独立证据；没有该主播记录时不改变历史概率。
- 概率接近均衡、模型分歧或近期明显失准时撤回方向。一次失败不会机械反向，也不因等待太久强制输出。大小和单双分别评估。

旧 V4 引擎仅保留为对照，其完整验证段、序贯证据和误报上限**不适用于 V5 主参考**。V5 页面不宣称已建立统计显著优势。个人实际/模拟行为用于分组复盘，暂不作为预测输入；无法凭个人输赢推断后台动机。

这些参数是待检验的工程设定，不是已经证明有效的博彩规律。非随机不等于可预测；存在操控也不代表仅靠可见历史就能识别对方策略。若开奖独立且公平，历史不能提高下一期长期命中率。更快变化的百分比不代表更高准确率。

## 验证与资金记录

- 仅将 V5 开奖前手动锁定、已录入结果且场次未作废的记录纳入验证。未锁定、旧版和截图记录不混入。
- 同期比较基准、近期、顺序、仅历史、加入主播、本版及旧版概率的 Brier 误差。加入主播与本版当前相同，保留命名用于识别输入来源，不是独立证据。
- 方向命中率同时显示输出轮数、覆盖情况和最长观望轮数；本版、旧版与固定大/单对照使用同一批本版出方向的期次，不能只挑命中的结果。
- 删除带验证协议的结果会使所属场次验证作废；锁定后修改历史会阻止该期正常验证。漏期及无结果的锁定记录均保留数量和导出明细，但漏期仍可能造成选择偏差，不能据此声称完整验证。
- 参与方式分为观望、模拟选择、实际参与记录。方向和可选金额都要在开奖前锁定；实际记录不影响模拟本金，本页面不会执行投注。
- 填金额时最低 2 元，固定十进制赔率 1.96（返还含本金），无返点设定。仅记录手动金额，不提供追损或自动加注。该赔率无额外费用/返点时的盈亏平衡胜率约 51.02%，预测点估计跨线不代表优势已成立。
- CSV 同时导出结果、锁定概率、参与结算、漏期/待开奖留痕及完整 JSON 审计字段；支持自定义网页标题和截图 OCR 核对补录。

## 存储和打开方式

电脑、手机都可打开同一网址，但**记录仍存于各自浏览器的 localStorage，不是云同步**。更换浏览器、清理站点数据可能失去记录，请先导出留存。不存在账号系统、云数据库或官方开奖接口。

本地可直接打开 `index.html`；或运行 `start.bat`，用 `http://localhost:8080` 访问。同一 Wi-Fi 下的手机可访问 `http://电脑IPv4地址:8080`，视电脑防火墙规则而定。

正常使用不请求外部数据。截图识别首次需要联网加载 Tesseract.js 和识别数据，图片在本机处理，必须人工核对后导入。支持 Web Locks 的浏览器串行处理多标签页写入；不具备安全多标签能力时会提示关闭其他页面。

## 开发验证

```powershell
node --test tests/model-core.test.cjs tests/live-model.test.cjs
node tests/live-null-stress.cjs
```

第二项生成固定种子的 500 个公平骰子场次，每场 60 轮，检查预测先于结果、命中率保持在随机基准附近。它是回归测试，不是现实效果保证。旧 `tests/fair-null-stress.cjs` 只测试保留的 V4 引擎。

界面测试需已提供 Playwright，并启动本地 HTTP 服务：

```powershell
$env:K3_TEST_URL = 'http://127.0.0.1:8125/'
# 如未安装 Playwright 自带浏览器，可指定 K3_BROWSER_PATH 为本机 Edge/Chromium 的完整路径。
node tests/ui-smoke.cjs
node tests/storage-smoke.cjs
```

覆盖移动端/桌面、10 轮启动、锁定后刷新及结算、跳过留痕、导出、模拟与实际分离、并发写入、旧数据隔离、删除失效和异常历史变动。截图可通过 `K3_SCREENSHOT_DIR` 输出到指定目录。
