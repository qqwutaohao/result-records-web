# 结果记录台

一个无需安装依赖的响应式网页，用来快速记录三个骰子结果，并更新大小、单双两组历史模型参考值。

线上地址：<https://qqwutaohao.github.io/result-records-web/>

## 当前功能

- 首页只需输入三个 `1–6` 的数字，例如 `425`、`4 2 5` 或 `4,2,5`；
- 自动计算和值、大小和单双；三同号不计大小，但仍按和值计入单双；
- 大与小合计 100%，单与双合计 100%；
- 固定 `50% / 50%`、静态 `Beta(10,10)` 贝叶斯和带 20 轮半衰期的动态贝叶斯同时在后台预测；
- 每条新记录都会冻结三套模型在开奖前给出的概率，并用同一批后续结果公平比较；
- 每 20 轮组成一个验证段：段开始时，大小和单双分别按各自 Brier Score 锁定展示模型，段内不再切换；
- 第一段固定使用 50% 基准；之后没有模型胜出的一组自动保持 50%；
- 20–99 条标记为“实验领先”，100 条以上才标记为“当前最优”；
- 模型排行榜分别显示大小、单双与综合 Brier Score，并展示非 50% 方向的历史命中率；
- 分别计算候选模型相对 50% 基准的近似 95% Brier 差值区间，显示“收集中、优势未确认、初步优势、未优于基准”；
- 旧场次不改变当前场次概率，只统计模型能否跨场重复胜出；至少 3 个满 20 轮的场次、同一模型胜出不少于 3 场且胜率达到 60%，才显示“多场稳定”；
- 跨自然日、间隔超过 30 分钟或点击“新场次”后重新累计，旧记录继续保留；
- 支持自定义标题、截图 OCR 补录、CSV 导出和本地历史长轴；
- 支持设置模拟本金，并手动记录大、小、单、双方向的金额测试；最低投入 2 元，固定十进制赔率 1.96；
- 旧版主播记录继续保留和展示为历史结果，但不再参与主播预判或主播命中统计。

## 打开方式

电脑直接双击 `index.html` 即可使用。

如需让同一 Wi-Fi 下的手机访问：

1. 双击 `start.bat`；
2. 电脑打开 `http://localhost:8080`；
3. 在 PowerShell 运行 `ipconfig`，找到电脑的 IPv4 地址；
4. 手机打开 `http://电脑IPv4地址:8080`。

截图识别第一次使用时需要联网加载 Tesseract.js OCR 组件和英文数字识别数据。图片在浏览器本地处理，识别候选必须人工核对后才会写入记录。

## 模型边界

模型输出是历史模型之间的样本外比较结果，不是开奖机制的真实预测概率。旧版记录和截图记录可以帮助计算当前概率，但由于没有同时冻结三套开奖前预测，不会进入模型排行榜。若每期开奖结果相互独立且骰子公平，历史结果不会提高下一期长期命中率。金额功能只记录用户手动输入的测试，不推荐方向或投入额。
